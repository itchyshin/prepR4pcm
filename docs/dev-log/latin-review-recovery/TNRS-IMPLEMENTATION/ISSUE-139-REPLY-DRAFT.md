I have a local prototype for an optional, review-only TNRS adapter. It queries one selected botanical source and offers a candidate only when the accepted name matches exactly one tip in the supplied tree. It preserves the service result and score for review, and it does not alter the mapping or apply a suggestion automatically. The adapter restores a path for useful name-resolution suggestions; spelling similarity alone does not establish that two valid taxa are the same.

The adapter tests and full package test suite pass, and the new Latin matching vignette runs.
