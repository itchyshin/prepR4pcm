# Round 15: pr_get_tree name-matching cascade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `pr_get_tree()`'s name handling honest: (1) always pre-normalise via `pr_normalize_names()`, (2) report `matched`/`unmatched` against the user's *original* input (never against TNRS-resolved or normalised intermediates), (3) surface TNRS substitutions as auditable replacements rather than silent corrections, (4) report multi-tree richer (n_requested, tip-set-consistency, dropped-per-tree).

**Architecture:** All name-handling logic moves from per-backend wrappers up into `pr_get_tree()`'s top-level dispatcher. Each backend wrapper now receives a single, pre-normalised `species_query` vector and returns just `tree` + `matched_query` (which subset of the query the backend resolved). The dispatcher then maps `matched_query` back to original input via a tracked `original → normalised → tnrs → query` mapping table, computes `matched`/`unmatched` against original input, and packs the multi-tree reporting fields. The accounting invariants (`matched ⊆ unique(input)`, `length(matched)+length(unmatched)==length(unique(input))`) are enforced inside the dispatcher's tail with `stopifnot()` calls — they cannot fail silently.

**Tech Stack:** R 4.1+, testthat (edition 3), the package's existing `pr_normalize_names()`, no new dependencies.

**Issues addressed (DO NOT CLOSE — let Ayumi close):** #72, #73, #75, #76.

## Internal contract changes (lock these in here so types match across tasks)

`pr_get_tree()` returns a `pr_tree_result` (S3) with:

```
list(
  tree         = <phylo or multiPhylo>,
  matched      = <character vector — subset of unique(input)>,
  unmatched    = <character vector — subset of unique(input), disjoint from matched>,
  source       = <single string from the source enum>,
  backend_meta = list(
    n_queried              = <integer>,   # length(unique(input))
    n_requested            = <integer>,   # the n_tree arg (NEW)
    n_returned             = <integer>,   # number of trees actually returned
    n_matched              = <integer>,   # length(matched)
    citations              = <backend-specific>,
    tnrs_replacements      = <named character vector or NULL — original → resolved>,  # NEW
    tip_set_consistent     = <logical scalar; TRUE for single phylo>,                  # NEW
    dropped_per_tree       = <list of character vectors, NULL for single phylo>,       # NEW
    tree_provenance        = <existing>
  )
)
```

Internal per-backend wrapper contract (`.pr_get_tree_<src>(species_query, n_tree, ...)`) is **simplified** — it now just returns:

```
list(
  tree         = <phylo or multiPhylo>,
  in_query     = <logical vector, length == length(species_query) — which queries did this backend resolve?>,
  citations    = <backend-specific or NULL>
)
```

The wrapper no longer computes `matched`/`unmatched`. The dispatcher does it once, against original input, after the wrapper returns.

1. Capture `original_input <- unique(stats::na.omit(species))` early
2. Compute `species_normalised <- pr_normalize_names(original_input)`
3. Run TNRS preflight on `species_normalised` if requested; track replacements as a named char vector `tnrs_replacements`
4. Build `species_query <- ifelse TNRS replaced, resolved, normalised`
5. Dispatch to backend wrapper with `species_query`; wrapper returns `tree` + `in_query` + `citations`
6. Map `in_query` back to `original_input` index, build `matched` / `unmatched` from original input
7. Compute multi-tree reporting (`tip_set_consistent`, `dropped_per_tree`) if `inherits(tree, "multiPhylo")`
8. Run final `stopifnot()` invariants
9. Pack result

- [ ] **Step 1: Add a helper `.pr_resolve_query()` that returns the full mapping table**

Insert after the existing `.pr_tnrs_preflight` definition (around line 525):

```r
# Internal: build the original→normalised→tnrs→query mapping table
# used to drive accounting in pr_get_tree(). Returns a list:
#   $original  : character — unique input, in original form
#   $normalised: character — pr_normalize_names(original)
#   $resolved  : character — same length, TNRS resolved where applicable
#   $query     : character — what gets passed to the backend
#   $tnrs_replacements: named char (orig -> resolved) for *changed* names, or NULL
.pr_resolve_query <- function(species, source, tnrs) {
  original   <- unique(stats::na.omit(as.character(species)))
  normalised <- pr_normalize_names(original)

  # TNRS preflight: same gating rules as before, but now we keep both the
  # input and the result so we can report substitutions explicitly.
  needs_tnrs_default <- source %in% c("fishtree")
  do_tnrs <- switch(tnrs,
    auto    = needs_tnrs_default,
    always  = TRUE,
    never   = FALSE
  )
  resolved <- normalised
  tnrs_replacements <- NULL
  if (do_tnrs && requireNamespace("rotl", quietly = TRUE)) {
    tnrs_res <- tryCatch(
      rotl::tnrs_match_names(normalised),
      error = function(e) NULL
    )
    if (!is.null(tnrs_res) && !is.null(tnrs_res$unique_name)) {
      replaced_idx <- !is.na(tnrs_res$unique_name) &
                       nzchar(tnrs_res$unique_name) &
                       tnrs_res$unique_name != normalised
      resolved[replaced_idx] <- tnrs_res$unique_name[replaced_idx]
      if (any(replaced_idx)) {
        tnrs_replacements <- setNames(
          resolved[replaced_idx],
          original[replaced_idx]
        )
        # One-shot informative warning so silent name substitution is
        # visible; users can still inspect the full table via
        # backend_meta$tnrs_replacements.
        cli::cli_warn(c(
          "TNRS replaced {length(tnrs_replacements)} input name{?s}.",
          "i" = "See {.code result$backend_meta$tnrs_replacements} for the full mapping.",
          ">" = paste0("e.g. ",
                       paste(sprintf("{.val %s} -> {.val %s}",
                                     names(tnrs_replacements)[seq_len(min(3, length(tnrs_replacements)))],
                                     unname(tnrs_replacements)[seq_len(min(3, length(tnrs_replacements)))]),
                             collapse = ", "))
        ))
      }
    }
  } else if (do_tnrs && !requireNamespace("rotl", quietly = TRUE)) {
    if (!isTRUE(getOption("prepR4pcm.tnrs_warning_shown"))) {
      cli::cli_warn(c(
        "TNRS preflight requires {.pkg rotl}; skipping.",
        "i" = 'Install with {.code install.packages("rotl")} for higher match rates with backends like {.val {source}}.',
        ">" = "(This warning appears once per session.)"
      ))
      options(prepR4pcm.tnrs_warning_shown = TRUE)
    }
  }

  list(
    original          = original,
    normalised        = normalised,
    resolved          = resolved,
    query             = resolved,        # backends receive `resolved`
    tnrs_replacements = tnrs_replacements
  )
}
```

- [ ] **Step 3: Add the post-dispatch accounting block (matched/unmatched against original)**

Immediately after the `switch()` above, insert:

```r
  # Map backend's per-query in/out flags back to original input.
  # `in_query[i]` says whether species_query[i] resolved at the backend;
  # we map that to "is original[i] matched?" — same index, since
  # .pr_resolve_query preserved order.
  in_query <- result$in_query
  if (!is.logical(in_query) || length(in_query) != length(resolved$original)) {
    cli::cli_abort(c(
      "Internal: backend wrapper returned malformed {.code in_query}.",
      "i" = "Expected {.cls logical} of length {length(resolved$original)}; got {class(in_query)} of length {length(in_query)}."
    ))
  }
  matched   <- resolved$original[in_query]
  unmatched <- resolved$original[!in_query]

  # Multi-tree reporting (#76) ---------------------------------------
  is_multi <- inherits(result$tree, "multiPhylo")
  n_returned <- if (is_multi) length(result$tree) else 1L

  tip_set_consistent <- TRUE
  dropped_per_tree   <- NULL
  if (is_multi && length(result$tree) > 1L) {
    tip_sets <- lapply(result$tree, function(t) sort(t$tip.label))
    tip_set_consistent <- all(vapply(tip_sets[-1L],
                                      function(s) identical(s, tip_sets[[1L]]),
                                      logical(1L)))
    if (!tip_set_consistent) {
      union_tips <- Reduce(union, tip_sets)
      dropped_per_tree <- lapply(tip_sets,
                                  function(s) setdiff(union_tips, s))
    }
  }

  # Accounting invariants — these CANNOT fail; if they do, it's a bug
  # in this dispatcher or a backend wrapper, not user error.
  stopifnot(
    "matched must be a subset of unique input" =
      all(matched %in% resolved$original),
    "unmatched must be a subset of unique input" =
      all(unmatched %in% resolved$original),
    "matched + unmatched must cover unique input" =
      length(matched) + length(unmatched) == length(resolved$original),
    "matched and unmatched must be disjoint" =
      length(intersect(matched, unmatched)) == 0L
  )

  # Build backend_meta with new fields (#72, #73, #76)
  backend_meta <- list(
```

```r
.pr_get_tree_clootl <- function(species, n_tree = 1L, ...) {
  if (!requireNamespace("clootl", quietly = TRUE)) {
    cli::cli_abort(
      c("The {.val clootl} backend requires the {.pkg clootl} package.",
        "i" = 'Install with: {.code pak::pak("eliotmiller/clootl")} (GitHub-only).',
        ">" = "See {.url https://github.com/eliotmiller/clootl} for details.")
    )
  }

  # Workaround for clootl 0.1.4: extractTree() / sampleTrees() call
  # `utils::data("clootl_data")` internally without `package =`. Without
  # clootl on the search path, that lookup warns "data set 'clootl_data'
  # not found" and the function errors. Temporarily attach clootl, then
  # detach on exit.
  if (!"package:clootl" %in% search()) {
    suppressPackageStartupMessages(attachNamespace("clootl"))
    on.exit(
      try(detach("package:clootl", character.only = TRUE), silent = TRUE),
      add = TRUE
    )
  }

  # The dispatcher has already pr_normalize_names()-ed `species`. We
  # send it through verbatim.
  call_args <- list(...)
  call_args$species <- species
  if (n_tree > 1L) {
    if (is.null(call_args$count)) call_args$count <- n_tree
    tree <- do.call(clootl::sampleTrees, call_args)
  } else {
    if (is.null(call_args$force)) call_args$force <- TRUE
    tree <- do.call(clootl::extractTree, call_args)
  }

  if (is.null(tree) || !(inherits(tree, "phylo") || inherits(tree, "multiPhylo"))) {
    cli::cli_abort(c(
      "{.pkg clootl} returned no tree for this species list.",
      "i" = "No queried species matched the requested eBird / Clements taxonomy.",
      ">" = "Check the names in {.arg x} or call {.fn reconcile_suggest} against a Clements-compatible reference."
    ))
  }

  # Compute in_query: which queries does the returned tree contain?
  ref_tips <- if (inherits(tree, "multiPhylo")) tree[[1]]$tip.label else tree$tip.label
  norm_query <- pr_normalize_names(species)
  norm_tip   <- pr_normalize_names(ref_tips)
  in_query   <- norm_query %in% norm_tip

  citations <- tryCatch(
    if (exists("getCitations", envir = asNamespace("clootl"), inherits = FALSE)) {
      get("getCitations", envir = asNamespace("clootl"))(
        if (inherits(tree, "multiPhylo")) tree[[1]] else tree
      )
    } else {
      NULL
    },
    error = function(e) NULL
  )

  list(tree = tree, in_query = in_query, citations = citations)
}
```
